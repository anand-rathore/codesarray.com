# Codesarray brand

The identity is called **Trace**: the letter C drawn as a circuit-board trace
with 45-degree corners, ending in a via. Handle on every platform: `@codesarray`.
Tagline: "Small games, and the code behind them."

Everything in this folder is generated by one script:

```sh
python3 brand/make_brand.py
```

It needs Pillow. It also copies the favicon, the apple-touch-icon and the
social preview image to the site root.

## Colour

| Name | Hex | Use |
|---|---|---|
| Graphite | `#1d2024` | The ground. Backgrounds of the site, banners and profile pictures. |
| Carbon | `#15171a` | Darker surface: code blocks, panels. |
| Bone | `#f3f1ec` | Type and the mark's stroke. |
| Steel | `#9aa0a6` | Secondary text. |
| Rule | `#34383e` | Lines, borders, background traces. |
| Signal orange | `#ff6a13` | The via, buttons, focus rings. One orange thing per view. |
| Ink | `#14171a` | The mark's stroke on light backgrounds. |

Orange is the only colour. It marks the end of something: the via on the mark,
the via at each section heading, the one primary button. Do not use it for
large fills or for body text.

The games keep their own palettes on their own pages (Blockfall navy and gold,
Paws & Perils warm pastel, Synapsy dusk and teal). The Codesarray mark sits on
its graphite tile there.

## Type

| Face | Use |
|---|---|
| Big Shoulders Display, weight 800 | The wordmark (always `CODESARRAY`, capitals) and headlines. |
| Barlow 400 / 500 / 600 | Everything else. |
| JetBrains Mono | Code only, with ligatures off. |

All three are open-licensed (SIL OFL); the files and licences are in `fonts/`.
The older faces (Space Grotesk, Archivo) stay there because the game pages
still use them.

## The mark

- Minimum size 16 px. Below 24 px use `logo/mark-tile.svg`, which has its own background.
- Keep clear space around it equal to the width of the stroke.
- On dark backgrounds: bone stroke, orange via (`mark-on-dark`). On light: ink stroke, orange via (`mark-on-light`).
- One colour only (video watermark, stamps): `mark-white.svg`.
- Do not rotate it, round the 45-degree corners, recolour the via, or put the stroke in orange.
- The lockup is the mark followed by `CODESARRAY`. Do not set the wordmark in another face or in lower case.
